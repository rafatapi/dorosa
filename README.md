# doRosa — landing page

Landing page estática e responsiva da marca de carvão vegetal doRosa.

Abra `index.html` diretamente no navegador ou use um servidor local simples.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `assets/css/style.css`: identidade visual e responsividade
- `assets/js/main.js`: menu móvel e animações suaves
- `assets/images/`: fotografias e imagem complementar
